# iOS

Open `PiDurableBot.xcodeproj` in Xcode and run the shared `PiDurableBot` scheme on an iOS simulator. The deployment target is iOS 18.0; the app uses SwiftUI and Swift 6.

The scaffold contains an empty assistant screen. Networking, chat, task controls, and notifications will follow the server protocol. Swift sources are not part of the Yarn workspaces.

For a device build, choose your development team and adjust the bundle identifier if needed. No signing credentials are checked in.
